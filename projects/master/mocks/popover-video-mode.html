Popover — Video mode armed

Video toggle on. The next Start also opens Photo Booth in a window.

Menu bar (unchanged by the toggle)
Popover

What changes versus idle

  • The switch fills green, the system on-state colour for .switch.
  • The icon swaps from video to video.fill, so the state survives Increase Contrast and greyscale, where colour alone would not.
  • Nothing else moves. The row width is fixed at 200pt and no control changes size.
  • The menu bar icon does not change. Video mode is an argument to the next recording, not a state of the app.

Behaviour

The toggle is read at the moment Start is pressed. When on, Photo Booth is opened in a window after the Start shortcut fires. It is not taken full screen: that path needed Accessibility permission and was removed. Photo Booth is not closed by Stop.

The toggle carries no text label. The camera symbol plus the switch is the whole control, which is what makes a 200pt row possible; the VoiceOver label "Include video in recording" carries the meaning for non-visual use.
