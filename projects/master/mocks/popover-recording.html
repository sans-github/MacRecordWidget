Recording, preview open — only the row changed

The preview is display-only in this state as in every other: nothing writes it to disk, and it is not part of the recording. What lands in Voice Memos is audio.

Behaviour

  • The panel stays open through Start and Stop by design, so Stop is one click away without reopening it. It closes only when the user clicks the menu bar icon.
  • isRecording flips only after the Shortcut URL opens successfully. A failed Start leaves the toggle off — there is no half-recording state.
  • Quit while recording stops the recording first, then terminates.
  • Under Reduce Motion the amber dot is drawn at full opacity and does not blink. Colour alone still distinguishes the state, and the panel's own toggle carries it unambiguously.

In-flight

Between the click and the state change, isInFlight disables the toggle. Starting takes at least 1.5s when Voice Memos is running, because it has to be quit first or macOS raises VMAudioServiceErrorDomain error 5. During that window the toggle is dimmed and still shows its previous state; there is no spinner.
