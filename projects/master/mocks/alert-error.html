Error — modal alert

Failures are reported by a critical NSAlert, not inside the popover. The 200pt row has no space for a message and no state to show one in.

⚠️
Could Not Start Recording
The recording shortcut could not be launched. Make sure a Shortcut named “Start” (or “Stop”) exists in the Shortcuts app. Detail: NSWorkspace.open returned false
OK

Behaviour after an error

  • isRecording is only set after the shortcut URL opens, so a failed Start leaves the row exactly as it was. There is no half-recording state to recover from.
  • The alert is app-modal and has one button. Dismissing it returns the user to the popover.
  • The alert appears over whatever is frontmost, because a menu bar panel cannot host a sheet.
