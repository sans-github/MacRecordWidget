Playback: The “Play Last” Control

One “play last” control, merged into the timer box, which already shows the last recording’s length while idle. Its glyph says which medium it will play. This page also covers what it costs the camera menu at each scale.

Requirement: before pressing, the user can tell at a glance whether “play last” will play audio or video. Three ways explored, Medium scale, last recording audio (top) and video (bottom).

Audio: waveform, the same mark as Voice Memos’ icon, which is where the file lives. Video: play.rectangle.fill, the standard “play a video” symbol. Both exist on macOS 14 (SF Symbols 1.0, macOS 11+). The glyph replaces the play triangle, so it costs no more width than a plain ▶. Tooltip names the medium and length: “Play last voice recording (04:17)” / “Play last video recording (01:36)”. With nothing recorded it shows play.fill, disabled, tooltip “No recording yet”. Known weakness: waveform on its own does not say “play”; the button capsule, the tooltip and the result of the press carry that.
